### 1.1 双通道交叉验证（判据已修订）

实验一与实验二必须同时在两个通道上运行：

- **(a) 实值 LTI 通道（主通道）**：`n = 64` 实值传感器，4 维状态（两个复共轭对），`r = 4`。构造方式见 `algorithm-spec.md` §2.1.1。对应"传感器实测振动信号"的应用场景。
- **(b) 复值解析信号通道（对照通道）**：`r = 2`，与原始文献设定对齐。

**修订说明**：原判据"两通道的偏差-方差结论必须同号同量级"**不可达**。实测两通道的偏差量级相差约一个数量级、且实值通道的降偏收益（10–29%）显著弱于复值通道（48–92%），详见 `algorithm-spec.md` §11.2。

修订后的判据为三条，全部满足方视为通过：

| # | 判据 | 说明 |
|---|---|---|
| X1 | **降偏方向一致** | 在两通道中，TDMD 的偏差均**不大于** DMD（在检测下限之上时须显著更小） |
| X2 | **方差代价一致** | 两通道的 `std` 比值须落在同一侧（均 ≥ 1 或均 ≤ 1），且差异不超过 5% |
| X3 | **定性分歧必须解释** | 若两通道在某假设上给出相反的定性结论（例如一通道 H3 成立、另一通道不成立），**不得择一报告**，必须给出机制解释并写入结果报告 |

X3 的存在意味着：**两通道出现分歧不是缺陷，而是必须解释的现象**。实值通道降偏收益较弱这一事实本身就是待解释的对象（见 `implementation-plan.md` 风险 R11）。

## 2. 实验一 · 偏差-方差分解

### 2.1 目的

量化 TDMD 相对标准 DMD 的**纠偏收益**与**方差代价**，并给出两者的净效应（MSE）。

### 2.2 可检验假设

| 编号 | 假设 | 判定统计量 |
|---|---|---|
| **H1** | 标准 DMD 存在系统性偏差，且随 SNR 降低而单调增大 | `bias_DMD(SNR)` 单调递增（SNR 递减方向） |
| **H2** | TDMD 的偏差显著小于标准 DMD | `|bias_TDMD| < |bias_DMD|`，且配对差 95% CI 不含 0 |
| **H3** | **TDMD 的方差大于标准 DMD（方差代价）** | `std_TDMD / std_DMD > 1`，配对 F 检验 |
| **H4** | 存在交叉点：低 SNR 下 MSE_TDMD 可能劣于 MSE_DMD | 存在 SNR* 使 `MSE_TDMD > MSE_DMD` |

> **H3 与 H4 是本项目最有价值的可检验假设。** 立项预期是"TDMD 纠偏、但有方差代价"，H3/H4 把这一预期变成可证伪的定量陈述。若 H3 被否定（TDMD 方差反而更小），那是需要重点解释的反常结果；若 H4 成立，则直接产出"低 SNR 下 TDMD 不值得用"的实用结论。
>
> **早期观测提示 H3、H4 可能均被否定**：在校验阶段（`J = 400`，见 `algorithm-spec.md` §11.2）复值通道的 `std` 比稳定落在 0.99–1.01，MSE 比一致小于 1。若正式实验确认，则结论为"**TDMD 在此设定下不以方差换偏差，且在 MSE 意义上全面不劣**"。这与立项的直觉预期相反，属于高价值结果，须在执行摘要中显著呈现，而非轻描淡写。

### 2.3 参数网格

**本实验为多轴扫描。** 四条轴及其必要性均由实测确定（ADR-011 ~ ADR-014）：

| 轴 | 取值 | 为什么必须有这条轴 |
|---|---|---|
| 通道数 `n` / 嵌入维数 `L` | `4, 8, 16, 32, 64` | **决定效应量能否被测出**。`n` 由 64 降到 4 时 DMD 偏差放大 6.8 万倍、所需 `J` 由 2.4e7 降到 1（`algorithm-spec.md` §7.1.4） |
| SNR | `20, 10, 5, 0, -5, -10` dB | 偏差 ∝ σ²、标准差 ∝ σ，所需 `J` 约按 `10^(SNR/10)` 变化 |
| 模态幅度比 | `1.0, 1.5, 2.0` | 非平衡使所需 `J` 降低 3.6–8 倍（ADR-012） |
| 通道形式 | `complex` / `real` / `hankel` | `hankel` 覆盖"单测点 + 时延"的真实部署形态（ADR-013） |

**默认网格**（`default_slices()`，共 29 个切点）：

```
complex : n ∈ {4,8,16,32,64} @ SNR=10dB
          SNR ∈ {20,10,5,0,-5,-10} @ n=8
          幅度比 ∈ {1.0,1.5,2.0} @ n=8, SNR=0dB
real    : n ∈ {4,8,16,32,64} @ SNR=10dB
          SNR ∈ {10,0,-5} @ n=8
hankel  : L ∈ {4,8,16,32} @ SNR=10dB
          SNR ∈ {10,0,-5} @ L=8
m = 200, J = 5000
```

### 2.3.1 报告口径（已由 SNR 分组改为实测判据）

原按 SNR 分 A/B 组的启发式**已废止**——它是在 `n=64` 下得出的，不能推广到小 `n`。
现行口径改由**两个实测判据**决定，见 `annotate_reportable()`：

| 判据 | 阈值 | 不满足时的处置 |
|---|---|---|
| 偏差可分辨 | `\|bias\|/std > 3.92/√J` | **只报上界 `δ_min`**，不得点估计、不得算降偏百分比 |
| 配对失败率 | `≤ 20%` | **不得报告偏差**（选择偏差风险，见 `algorithm-spec.md` §4.4） |

**两条都满足才可报告偏差点估计。** 网格点若落在低 SNR 或高 `n` 区，很可能两条都不满足——
这本身是结论（"该条件下偏差不可测"），不是失败。

### 2.3.2 工作点选择的强制流程

1. 先用 `J ≈ 1e3` 做小规模预扫描（几分钟）；
2. 检查 `|bias|/std`、所需 `J`、**配对失败率**三项；
3. 确认落在"可分辨 + 低失败率"区域后，才用正式 `J` 跑。

> **不得**跳过第 1–2 步直接跑正式实验。本项目曾因跳过该流程，
> 在 `n=64` 上白跑了一轮才发现效应根本不可测（风险 R16）。

### 2.4 输出物

1. `results/tables/exp1_bias_variance.csv` — 逐 `(通道, SNR, 模态, 方法)` 的 `bias, std, mse, rmse` 及 95% CI
2. `results/figures/fig1_bias_vs_snr.png` — 偏差随 SNR 变化，DMD 与 TDMD 双线，含对数纵轴
3. `results/figures/fig2_std_vs_snr.png` — 标准差随 SNR 变化（方差代价直接可视）
4. `results/figures/fig3_mse_decomposition.png` — 分组柱状图，每档 SNR 下 `bias²` 与 `var` 的堆叠分解，两法并列
5. `results/figures/fig4_ci_bars.png` — 偏差的点估计 + 95% CI 误差棒，标注各点的检测下限 `δ_min`

### 2.5 判定准则

**前置条件（对任一网格点成立才继续判定）**：

- 该点须满足 `|bias|/std > 3.92/√J`（可分辨）且 `配对失败率 ≤ 20%`；
- 不满足则该点**不参与假设判定**，只记录为"偏差不可测"或"选择偏差风险"。

| 编号 | 假设 | 判定统计量 |
|---|---|---|
| **H1** | 标准 DMD 的偏差随 SNR 降低而增大 | 在可分辨网格点上，`\|bias_DMD\|` 关于 SNR 单调递增（沿 SNR 轴） |
| **H2** | TDMD 的偏差显著小于标准 DMD | 配对差 95% CI 不含 0；`\|bias_TDMD\|/\|bias_DMD\| ≤ 0.60`（复值）/ `≤ 0.85`（实值） |
| **H3** | TDMD 存在方差代价（`std_TDMD > std_DMD`） | `std` 比值的配对 95% CI 下界 > 1 |
| **H4** | 存在 `MSE_TDMD > MSE_DMD` 的网格点（交叉点） | `MSE` 比值的配对 95% CI 下界 > 1 |
| **H2'** | ★ **偏差可分辨性随 `n` 增大而急剧下降** | `\|bias_DMD\|` 关于 `n` 单调递减；`log\|bias\|` 对 `log n` 的斜率显著为负 |
| **H2''** | ★ **`n` 小时偏差达工程不可接受量级** | `n=4` 处 `\|bias_DMD\|` 是否 ≥ 1%（振动监测中通常要求频率误差 < 0.5%） |

> **H2' 与 H2'' 是 ADR-013 的直接推论，也是本项目最重要的应用结论**：
> 它把"要不要用 TDMD"从方法选择问题转化为**传感器配置问题**——
> 少量测点下偏差可达百分级、TDMD 收益巨大；而高通道数阵列下偏差本就可忽略。

## 3. 实验二 · 样本量扫描

### 3.1 目的

验证两条关于样本量 `m` 的收敛性主张，并识别偏差是否存在"地板"。

### 3.2 可检验假设

| 编号 | 假设 | 判定统计量 |
|---|---|---|
| **H5** | 标准 DMD 的偏差**不随 `m` 下降** | `d log\|bias\| / d log m` 的 95% CI 覆盖 0 |
| **H6** | TDMD 的 RMSE 按 `O(1/√m)` 下降 | `d log RMSE / d log m` 的 95% CI 覆盖 −0.5 |
| **H7** | TDMD 的偏差衰减快于标准 DMD | 斜率差 `ŝ_TDMD - ŝ_DMD` 的 95% CI 上界 < 0 |
| **H8** | 标准 DMD 的 MSE 在 `m` 大时被 `bias²` 主导（偏差地板） | `var_DMD / MSE_DMD → 0` 随 `m` 增大 |

> **H5 是本项目最核心的结论。** 立项文档的表述为"标准 DMD 的偏差是否**不**随样本量下降"——注意这是**否定式**假设，其判定必须依赖区间估计覆盖 0，而不能依赖"看起来平"。因此斜率必须报告 95% CI，不能只报点估计。

> **SNR 档位已由 10 dB 修订为 −5 dB**（见 §3.3）。原因：10 dB 处偏差不可分辨，斜率拟合会退化为对噪声拟合。该修订由 `algorithm-spec.md` §7.1 的实测标定表支撑（ADR-011）。

### 3.3 参数网格

```
SNR_dB = -5                # 修订：原定 10 dB 处偏差不可分辨，见 algorithm-spec.md §7.1
m      ∈ {50, 75, 100, 150, 200, 300, 400, 500}
J      =  20000            # 嵌套前缀设计；标度律斜率需要高精度
m_max  =  500
```

嵌套设计与斜率估计方法见 `algorithm-spec.md` §7.3。**不得**对跨 `m` 的合并数据直接做 OLS。

### 3.4 输出物

1. `results/tables/exp2_sample_size_scan.csv` — 逐 `(通道, m, 模态, 方法)` 的 `bias, std, mse, rmse` 及 CI
2. `results/tables/exp2_slopes.csv` — 各方法的 `log|bias|–log m` 与 `log RMSE–log m` 斜率、95% CI、`R²`
3. `results/figures/fig5_bias_vs_m.png` — log-log 坐标，偏差随 `m`；DMD 期望近似水平线，TDMD 期望下降
4. `results/figures/fig6_rmse_vs_m.png` — log-log 坐标，附 `m^{-1/2}` 参考斜率线
5. `results/figures/fig7_bias_variance_mse_vs_m.png` — 三线图：`bias²`、`var`、`MSE` 随 `m`，两法并列，直观展示"偏差地板"

### 3.5 判定准则

- H5 成立：`|ŝ_bias,DMD| < 1.96 · SE(ŝ)`，即斜率与 0 无显著差异
- H6 成立：斜率 CI 覆盖 −0.5
- H7 成立：斜率差的 CI 上界 < 0
- H8 成立：`m ≥ 300` 时 `var_DMD / MSE_DMD < 0.3`

**若 H5 被否定**（标准 DMD 偏差确实随 `m` 下降），须排查三种可能原因后再下结论：
(a) 模态配对在不同 `m` 下发生了切换；(b) `m` 增大导致 `f̂` 的缠绕或近 Nyquist 效应；(c) 实现中存在未察觉的噪声轨迹不连续（破坏 `ΔX`/`ΔY` 重叠结构）。

## 4. 实验三 · 噪声估计敏感性

### 4.1 前置结论（必读）

按 `docs/algorithm-spec.md` §5.4 的规格结论，**原版 TDMD（算法 A2）不含噪声水平输入参数**，因此立项文档中"用偏离真实值的噪声估计运行 TDMD"这一实验在原始算法上**没有可执行的挂钩**。

实验三必须重新定义。以下给出三个方案，**建议采用方案 3A**，因为它直接对应"噪声估计不准时还能不能用"的原始关切，且不需要引入新的算法变体。

### 4.2 方案 3A（推荐）：秩估计对噪声水平的敏感性

**动机**：TDMD 的截断秩 `r̂` 在真实场景中需由数据推断，而秩判据依赖噪声水平的估计。这是 `σ̂` 在 TDMD 流程中**唯一自然且必经的入口**。

**做法**：

1. 定义秩估计器 `r̂ = R(σ̂)`，候选实现：
   - **能量阈值法**：保留累计能量占比 ≥ `1 - c·σ̂²/σ_1²` 的奇异值
   - **Marchenko–Pastur 法**：按随机矩阵理论噪声地板 `σ̂(√m ± √(2n))` 截断
   - **Gavish–Donoho 最优硬阈值**：`τ = σ̂ · ω(β) · median(奇异值)`
   - **残差法估计 `σ̂`**：`σ̂ = ‖X - Ū_r Σ̄_r V̄_r*‖_F / √(n·m)`（自举估计，无需外部输入）

**参数网格**：

```
SNR_dB ∈ {10}
m      ∈ {200}
J      =  5000
σ̂/σ_true = k ∈ {0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0}     # 人工失配
以及:  σ̂ 由残差法自举估计（k 未知，考察数据驱动方案的实测表现）
秩判据 ∈ {energy, marchenko_pastur, gavish_donoho}        # 规格见 algorithm-spec.md §10
```

**判定与产出**：

- 绘制 `bias(k)`、`std(k)`、`MSE(k)` 曲线 → 得到**鲁棒区间** `[k_lo, k_hi]`，定义为使 `MSE_TDMD(r̂(k)) < MSE_DMD` 的 `k` 集合
- 关键量：**`k` 失配引起的秩误判率** `P(r̂ ≠ r_true)`，以及秩误判导致的 MSE 退化倍数
- 结论形态："σ̂ 在 `[a, b]` 倍真值范围内，TDMD 仍优于 DMD；超出该范围，秩估计失效导致 TDMD 收益消失"

### 4.3 方案 3B（可选）：正则化 TDMD 的鲁棒边界

**动机**：原文明确将加权/正则化 TLS 列为 *outside the scope of this study... the focus of ongoing work*。实现该变体是本项目的**增量贡献**，且其中正则参数 `λ` 通常 `∝ σ²`，`σ̂` 在此有真实入口。

**做法**：实现正则化 TLS（RTLS）变体 `Ã_λ = (Ũ*Ũ + λ(σ̂) I)^{-1} Ũ*Ȳ V̄ Σ̄^{-1}`，扫描 `λ(σ̂)` 的标定函数与失配误差。

**代价**：需先完成 RTLS 的推导与数值验证（含正则参数选取准则如 L 曲线/GCV），工作量约等于一个独立子课题。

### 4.4 方案 3C（可选）：噪声结构失配

**动机**：TDMD 隐含白噪声假设。考察真实噪声为有色/时间相关时的失效边界。

**关键注意**：由 `algorithm-spec.md` §5.4 的代数分析，**行方向的白化不改变 TDMD 结果**。因此要使实验有意义，必须引入**时间方向（列方向）的相关性**，即 `E[ε(t)ε(t')] ≠ 0`，使 `Z` 的行空间与白化后的行空间产生实质差异。实现前必须先完成该推导并写入代码注释，**不得凭直觉设定加权形式**。

**建议**：先执行 3A；3B/3C 作为立项扩展项，待 3A 结论产出后按剩余预算决定。

## 5. 汇总与决策表

本表是立项"预期结论"的落点：给出"什么噪声和样本条件下，TDMD 值得用、标准 DMD 够用、或者两者都不行"的实用判断。

**表格分为两栏：左栏是待检验的先验预期（基于理论与早期观测），右栏是待数据填充的实测结论。右栏在实验完成前一律为 `TBD`。**

| 噪声条件 | 样本条件 | 先验预期 | 实测结论（待填） |
|---|---|---|---|
| 高 SNR（≥ 20 dB） | 任意 | 标准 DMD 够用（偏差接近检测下限） | `TBD` |
| 中 SNR（10–15 dB） | 大 `m`（≥ 200） | TDMD 值得用 | `TBD` |
| 中 SNR（10–15 dB） | 小 `m`（≤ 75） | 视 MSE 交叉点（H4） | `TBD` |
| 低 SNR（≤ 5 dB） | 任意 | 预期"两者都不行"，但早期观测不支持，见下 | `TBD` |
| 秩估计失效（`k > k_hi`） | — | 退回标准 DMD | `TBD` |

**先验预期需按早期观测修正的两处**：

1. **"低 SNR 下 TDMD 方差代价超过纠偏收益"这一预期与早期观测相悖。** 实测 `std` 比稳定在 0.99–1.01，未观察到方差代价；且 SNR 越低降偏越强。若正式实验确认，则低 SNR 档结论应为 **"TDMD 仍然值得用"**，而不是"两者都不行"。H4（MSE 交叉点）可能根本不存在。
2. **"高 SNR 下标准 DMD 够用"的判据须由检测下限决定**，而不是由主观印象。只有当 `|bias_DMD| < δ_min` 成立时才能声称"够用"；否则须报告偏差的实测值。

> 正栏与右栏的差异本身是有价值的产出——**先验预期被数据推翻，是合格的实验结果**。

## 7. 运行矩阵与算力预算

单次耗时**已实测**（Python 3.12.10 / numpy 2.5.3 / 单核 / `n = 64` / DMD+TDMD 两法合计）：

| `m` | 单次耗时 |
|---|---|
| 200 | 13.7 ms |
| 500 | 26.5 ms |

据此推算：

| 实验 | 配置 | 推算耗时 |
|---|---|---|
| 实验一（主网格） | 2 通道 × 3 SNR × `J = 5000` | ≈ 6 min |
| 实验一（扩展网格） | 2 通道 × 8 SNR × `J = 1000` | ≈ 4 min |
| 实验二 | 2 通道 × `J = 20000` × 8 个 `m`（嵌套） | ≈ 60 min |
| 实验三 | 2 通道 × 7 个 `k` × `J = 5000` × 3 判据 | ≈ 25 min |
| **合计** | | **≈ 1.5 小时（单核）** |

SVD 规模均为 `2n × m ≤ 128 × 500`。**单机单核串行 + 向量化即可承受，不需要并行框架**——多进程会显著增加种子管理与结果归并的复杂度，收益不成比例。

若需加速，优先考虑在实验二中对每个实现复用 `Ṽ_r` 的增量 SVD，而非引入多进程。

> **算力预算是充裕的，因此不必为省时间牺牲 `J`。** 实验二占总工时的大头（约 2/3），而它恰好是对统计精度要求最高的一环——标度律斜率的置信区间直接依赖 `J`。这里省时间是最不划算的取舍。

### 8.2 实验十一 · 原文 Figure 1 复现（外部一致性验证）

**本项目唯一与外部文献挂钩的实验。** 目的不是提出新结论，而是回答
"你怎么知道实现对了"——此前全部证据都是内部自洽的。

**原文**：Hemati, Rowley, Deem & Cattafesta, *TCFD* **31**(4):349–368, 2017,
§3 "DMD on a linear system" 与 Figure 1（arXiv:1502.03854）。

**设定**（逐项照搬原文）：

| 项 | 取值 |
|---|---|
| 状态空间 | `C^2`，动力学 `(x1,x2) -> (lam1 x1, lam2 x2)` |
| 特征值 | `(lam1, lam2) = (1.02 e^{0.1i}, 1.04 e^{0.3i})`（**非共轭**，模分别为 1.02 / 1.04） |
| 观测 | 随机线性映射 `C^2 -> C^250`，即 `n = 250`、`r = 2` |
| 快照对 | `m ∈ {100, 200, 500}` |
| 构造 | 拼接 `{5, 10, 25}` 段、每段 **20** 个快照，**每段由不同初态初始化** |
| 噪声 | 加性圆对称复高斯 `(dX, dY) ~ CN(0, 0.05)`（**绝对**口径） |
| 实现次数 | 原文 **200**；本项目 `J = 1500`（提高分辨率以判定"无偏"） |

**三部分判据**：

- **A · 复现**：无噪退化门（D1）必须通过（`< 1e-10`）；报告两法的谱偏差
  （复数域 `|mean(lam_hat) - lam|`）、离散度与可分辨性。
  原文主张为"TDMD 基本无偏、方差略紧于标准 DMD"。
- **B · 机制**：扫 `sigma^2 ∈ {0.05, 0.2, 0.8, 3.2}`，拟合
  `log|bias| ~ a·log(sigma^2)`，**且只用「偏差可分辨」的点**（不可分辨时点估计由 MCSE 主导，斜率纯属噪声）。
  上界取 3.2 就是为了让**两法**都有足够多的可分辨点。
  **该判据不受原文未给出的观测矩阵尺度影响**，故比在单一 SNR 上比较更可靠。
- **C · 代码路径**：交付的 `DMD`/`TDMD` 与**按原文公式内联**的参考算子在同一数据上
  特征值差 `< 1e-10`；并确认 `tdmd_left_star` 在原文算例上失败、
  `tdmd_left_pinv` 与正确版等价——即 §8.2.1 所要求的"用原文自身算例标定负对照"。

> ⚠️ **三处原文未规定、但会改变结论的自由度**：
>
> ① **随机观测矩阵的尺度** ⇒ 有效 SNR 是自由参数。噪声是绝对口径，而信号幅度由
> 观测矩阵尺度决定，原文未给。故"原文噪声水平下偏差是否可见"不是定义良好的问题；
> 本实验改用**偏差的标度指数**作判据（与信号绝对幅度无关）。
>
> ② **`dX` 与 `dY` 是否相关**。原文只写 `(dX, dY) ~ CN(0, 0.05)`。实测
> （`m=200`、`sigma^2=0.8`）降偏比在 `trajectory`（X/Y 噪声重叠）下为 **0.084**、
> 在 `independent`（各自独立）下为 **0.549**，**相差 6.5 倍**；且只有 `trajectory`
> 与原文"TDMD 基本无偏"一致（TDMD 偏差/MCSE 低于可分辨门）。
> 故实验以 `trajectory` 为主口径（与 ADR-005 一致），`independent` 作对照。
>
> ③ **拼接方式**。多段数据必须**按块**拼接（`X = [X1|X2|...]`、`Y = [Y1|Y2|...]`）。
> 若改成"先拼轨迹再整体切片"，段边界会产生**缝接列对**：前一段的**最大**列
> （`lam^20 x0`）与后一段的**最小**列（`x0`）配成一对，`||X_k||/||Y_k||` 由
> ~0.97 散到 0.59–4.78。实测把**无噪**恢复误差由 `1e-16` 抬到 `7.5e-2`、
> 含噪偏差**放大 360 倍**。注意 `col(Y) ⊆ col(X)` 这个判据**识别不出**缝接 ——
> 两种构造下所有列都落在同一 `r` 维空间里；真正的判据是**无噪恢复误差**。
> 已固化为回归测试 `test_seam_construction_breaks_operator_relation`。

> ⚠️ **一处对原文定性表述的限定**：实测两法偏差的标度指数**都接近 1**
> （同为 `O(sigma^2)`，TDMD 的系数小得多），**不是** `a_TDMD ≈ 2`。
> 故原文的"TDMD 基本无偏"应读作**"偏差降到不可分辨"**，而非"偏差恒为零"。

> ⚠️ **原（已被上文取代）两处保真度要点**（详见 `docs/final-report.md` §2.15 与 §8.2.1 的勘误）：
>
> ① **原文未给出观测矩阵的尺度**，而噪声是绝对口径 —— 故**有效 SNR 是一个自由参数**。
> 这也是必须做 B 部分的原因：标度指数与信号的绝对幅度无关。
>
> ② **多段数据必须按块拼接**：`X = [X1|X2|...]`、`Y = [Y1|Y2|...]`。
> 若改成"先把各段轨迹首尾相接、再整体切片"，段边界会产生**缝接列对**：
> 前一段的**最大**列（`lam^20 x0`）会与后一段的**最小**列（`x0`）配成一对，
> `||X_k||/||Y_k||` 由 ~0.97 散到 0.59–4.78。实测把**无噪**恢复误差抬到
> `7.5e-2`、含噪偏差放大 **360 倍**。已固化为回归测试
> `test_seam_construction_breaks_operator_relation`。
