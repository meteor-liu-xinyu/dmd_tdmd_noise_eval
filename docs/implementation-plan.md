## 2. 研究问题与可检验假设

### 2.1 研究问题

> 在有限样本、双侧含噪的快照数据下，标准 DMD 的频率估计存在多大的系统性偏差？TDMD 能以多大的方差代价消除该偏差？该收益在何种 (SNR, m, 噪声水平认知) 条件下成立？

### 2.2 假设体系

立项文档给出的定性预期被拆解为 8 条可证伪假设。**假设不是装饰，每一条都必须对应到具体的判定统计量，并且允许被否定。**

| 编号 | 假设 | 归属 | 判定统计量 |
|---|---|---|---|
| H1 | 标准 DMD 偏差随 SNR 降低单调增大 | 实验一 | `bias_DMD(SNR)` 单调性 |
| H2 | TDMD 偏差显著小于标准 DMD | 实验一 | 配对差 95% CI 不含 0 |
| H3 | TDMD 存在方差代价（`std_TDMD > std_DMD`） | 实验一 | `std` 比值的 CI 下界 > 1 |
| H4 | 低 SNR 下 TDMD 的 MSE 可能劣于 DMD（存在交叉点） | 实验一 | `MSE` 比值 CI |
| H5 | 标准 DMD 偏差不随 `m` 下降（偏差地板） | 实验二 | `d log|bias| / d log m` 的 CI 覆盖 0 |
| H6 | TDMD 的 RMSE 按 `O(1/√m)` 下降 | 实验二 | 斜率 CI 覆盖 −0.5 |
| H7 | TDMD 偏差衰减快于标准 DMD | 实验二 | 斜率差的 CI 上界 < 0 |
| H8 | 大 `m` 时标准 DMD 的 MSE 被 `bias²` 主导 | 实验二 | `var/MSE` 阈值 |

**H3、H4 是项目最有信息量的两条假设**：它们把"TDMD 更好"这一朴素预期转化为"TDMD 在何处更好、在何处更差"的定量划界，正是立项"预期结论"的落点。

### 2.3 结论的认知边界（必须在报告中声明）

1. 本项目结论限于**加性高斯白噪声 + 线性双模态振荡系统**。非线性系统、有色噪声、过程噪声（process noise）不在覆盖范围内。原文亦指出过程噪声与测量噪声的分离是独立问题。
2. TDMD 的无偏性依据来自 TLS 在误差变量模型下的渐近理论，**理论保证是"`m → ∞` 时收敛"**；本项目正是要填补"有限 `m` 时差多少"的空缺，因此结论以经验曲线与标度律为主，不以理论证明为主。
3. 模态数 `r` 在实验一、二中使用 **oracle 设定**（`r = r_true`）。这隔离了秩选择误差，对"纯偏差-方差分解"是正确选择；但也意味着结论是**上界性质的乐观估计**。实验三专门承担秩选择误差的评估。

│  L0  配置层     configs/*.yaml  →  解析 + 校验 + 指纹        │

                            ▼
┌─────────────────────────────────────────────────────────────┐

│                 sim/noise       单条噪声轨迹 + SNR 反解       │

┌─────────────────────────────────────────────────────────────┐

                            ▼
┌─────────────────────────────────────────────────────────────┐
│  L3  统计层     metrics          偏差/标准差/MSE/RMSE/CI      │
│                 mc              蒙特卡洛驱动、配对、嵌套、种子 │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  L4  实验层     experiments/exp1_bias_variance                │
│                 experiments/exp2_sample_scan                  │
│                 experiments/exp3_noise_sensitivity            │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  L5  呈现层     report/tables  → CSV                          │
│                 report/figures → PDF + PNG（由 CSV 驱动）      │

**单向依赖约束**：L(n) 只能依赖 L(≤n)。`estimators/` 不得 import `experiments/`；`report/` 不得 import `sim/`（只读 CSV）。这条约束保证图表脚本无法绕过数据层硬编码数值。

## 5. 接口契约

### 5.1 估计器统一接口

所有估计器实现同一接口，使实验脚本对方法无感知，新增方法（如 fbDMD、optimized DMD）无需改动实验层：

```python
class Estimator(Protocol):
    name: str

    def fit(self, X: NDArray, Y: NDArray, r: int, dt: float) -> "EstimateResult":
        """X, Y: (n, m)；dt: 采样间隔（秒）"""

@dataclass
class EstimateResult:
    freqs: NDArray          # (r,) 升序，单位 Hz
    eigenvalues: NDArray    # (r,) 离散特征值 μ，与 freqs 同序
    modes: NDArray          # (n, r) 模态
    diagnostics: dict       # cond(Σ̄)、置零计数、near_nyquist 标志
```

`diagnostics` 字段为必需项，不得省略——数值病态是低 SNR 大 `m` 下的实际风险，必须可事后审计。

### 5.2 结果数据契约

`results/raw/` 下的每个 `.npz` 必须包含：

| 键 | 形状 | 含义 |
|---|---|---|
| `freq_hat` | `(J, n_method, n_modes)` | 全部估计值 |
| `pair_ok` | `(J, n_method)` | 配对成功标志 |
| `meta` | JSON 字符串 | 配置指纹、`noise_mode`、`snr_convention`、两通道标识、`J` |

聚合 CSV 必须携带同一配置指纹，使图表可追溯到唯一的运行。

### 5.3 配置架构

`configs/base.yaml` 承载共用参数，实验 YAML 通过 `extends` 覆盖。`config.py` 负责：

1. 合并与类型校验（用 `dataclass` + 显式 range 检查）
2. 六条设计约束 C1–C6 的校验（见 `algorithm-spec.md` §2.2；硬阈值拒绝 + 警戒带告警）
3. 计算 SHA-256 配置指纹（规范 JSON，键排序，浮点格式统一）

**任何未经校验的配置不得进入实验流程。**

## 6. 实施阶段与验收门

每个阶段设**验收门（gate）**：门未通过不得进入下一阶段。这是保证最终结论可信的核心机制——本项目的主要风险不是"跑不出来"，而是"跑出来了但实现有隐蔽错误"。

### M0 · 工程骨架

**产出**：目录结构、`pyproject.toml`、配置加载与校验、CI 化的 `pytest` 入口。
**验收门 G0**：`pytest` 可运行；非法配置被正确拒绝（T10 通过）。

### M1 · 仿真器

**产出**：`sim/oscillator.py`、`sim/noise.py`。
**验收门 G1**：
- T4（秩正确性）、T5（SNR 反解一致性 < 1%）、T6（噪声轨迹重叠性精确成立）通过
- 无噪时快照矩阵 `Z` 的条件数可报告，且第 `r_true+1` 个奇异值 `< 1e-10 · σ_1`
- 逐模态局部 SNR 输出与聚合 SNR 的换算关系在报告中说明

### M2 · 标准 DMD

**产出**：`estimators/dmd.py`、`estimators/pairing.py`。
**验收门 G2**：T1（无噪精确恢复，相对误差 < 1e-10）、T9（定序不变性）通过。

### M3 · TDMD

**产出**：`estimators/tdmd.py`、T11 判据的参考实现标定。
**验收门 G3（已重新设计）**：原设计仅要求 T2、T3（无噪退化判据 D1）通过，**该设计经实测证伪，不足以拦错**。

| 子门 | 内容 | 状态 |
|---|---|---|
| G3-a | T2、T3 通过（无噪时 TDMD 退化为 DMD，`< 1e-10`） | ✅ 已通过（实测 1.30e-15 实 / 4.40e-16 复） |
| G3-b | **T11 去偏有效性**：`SNR=−5 dB`、`m=200`、`J≥4000` 下 `\|bias_TDMD\|/\|bias_DMD\| ≤ 0.60` | ✅ 已通过（`tests/test_debias.py`） |
| G3-c | `Z` 的形状断言 `(2n, m)`，杜绝遗漏增广 | ✅ 已落地（`tdmd.py` Step 1） |
| G3-d | 负对照被 T11 拒绝（遗漏增广 → 降偏比 = 1.0） | ✅ 已通过 |
| G3-e | 用**原文自身算例**验证正确实现能复现原文结论 | ✅ 已通过（原文 Figure 1：`m=500` 降偏 55–77%） |

**为什么 G3-a 不够**：实测显示，把投影误改为使用 `Z` 的**左**奇异向量时，无噪条件下频率恢复误差仍为 `8.9e-16`——T1/T2/T3 全部通过。原因是无噪时 `rank(Z) = r` 恰为满秩，任何基于 `Z` 的正交分解都张成同一个 `r` 维子空间并给出精确算子。**错误只在含噪时显现。**

**G3-b 的标定基准（已解决）**：原计划"以自造的错误变体标定 T11"，该思路**已被证伪**——自造的 `U1⁺U2` 变体实测与正确实现特征值等价，不能充当反例。改用**原文自身算例**作基准：先确认正确实现能复现原文 Figure 1 的结论，再确认候选反例（`U1*U2`）在该算例上失败（偏差比为 12 倍）。

> **G3 已全部通过，项目的主要技术风险 R1 已闭环。**

### M4 · 统计层与双通道交叉验证

**产出**：`metrics.py`、`mc.py`、`test_cross_channel.py`。
**验收门 G4**：T7 通过——但**判据已修订**。原判据要求两通道"偏差-方差结论同号同量级"，实测**不可达**（两通道偏差量级相差约一个数量级，降偏收益 10–29% vs 48–92%）。修订后的三条判据 X1–X3 见 `experiment-protocol.md` §1.1：

- X1 降偏方向一致
- X2 方差代价一致
- X3 **定性分歧必须解释**（不得择一报告）

两通道仍是彼此独立的实现路径，其一致性仍是对流水线的有效校验；但"分歧"被重新定义为**待解释的现象**，而非实现缺陷的信号。

### M5 · 实验一

**产出**：exp1 脚本、`exp1_bias_variance.csv`、fig1–fig4。
**验收门 G5**：H1、H2、H3、H4 均有明确的"成立/不成立"结论，且每条结论附 CI。**允许 H3/H4 被否定**——否定结论同样是合格的交付。

### M6 · 实验二

**产出**：exp2 脚本、`exp2_sample_size_scan.csv`、`exp2_slopes.csv`、fig5–fig7。
**验收门 G6**：H5–H8 结论明确。若 H5 被否定，必须先完成 `experiment-protocol.md` §3.5 的三项排查并在报告中记录，方可提交结论。

### M7 · 实验三

**产出**：exp3 脚本、秩估计敏感性结果、fig8–fig9。
**验收门 G7**：至少完成**方案 3A**，给出鲁棒区间 `[k_lo, k_hi]` 与秩误判率曲线。

### M8 · 汇总与结论

**产出**：`decision.py` 生成的决策表（fig10）、结果报告。
**验收门 G8**：
- 决策表所有 `TBD` 被数据填充
- 所有图表可由 CSV 一键重生成（`scripts/make_all_figures.py`）
- 报告中显式声明 **本文件 §2.3** 的三条认知边界

## 7. 风险登记册

按"影响 × 概率"排序，每条给出**缓解措施**与**触发条件**。

| 编号 | 风险 | 影响 | 概率 | 缓解措施 |
|---|---|---|---|---|
| **R1** | **TDMD 投影子空间取错**（遗漏增广矩阵，或误用 `Z` 的左奇异向量而非右奇异向量） | 致命：全部结论失效 | 中 | **仅靠无噪判据无法拦截——已实测证伪**（误用左奇异向量时无噪误差仍为 `8.9e-16`）。缓解措施：① G3-b 的 T11 含噪去偏判据；② `Z` 形状断言；③ 代码评审逐行对照原文；④ **参考实现标定**（见 R12） |
| **R2** | **实验三前提不成立**（原版 TDMD 无噪声输入参数） | 高：实验三无法按立项原样执行 | **已确认发生** | 已在 `README.md` §5 与 `algorithm-spec.md` §5.4 记录；实验三改为方案 3A（秩估计敏感性），3B/3C 作为可选扩展 |
| **R3** | 偏差的 MC 估计不显著（`\|bias\| < δ_min`） | 中：结论只能报上界 | **已确认发生**（实值通道模态 1） | 公共随机数配对比较（消减差值的方差）；`J = 5000`（关键点 20000）；按 `algorithm-spec.md` §7.1 强制规则只报上界、不算降偏百分比 |
| **R4** | 模态配对在不同 `m` 下切换 | 中：伪造出"偏差随 m 变化"的假象 | 中 | 配对失败计数；设计约束 2 保证频率间隔 ≥ 25%；实验二 H5 的排查项 (a) |
| **R5** | 嵌套前缀设计引发的跨 `m` 相关性污染斜率估计 | 中：斜率 CI 失真 | 高（若直接合并 OLS） | 强制逐实现拟合斜率再跨实现统计（`algorithm-spec.md` §7.3），禁止合并 OLS |
| **R6** | `Σ̄^{-1}` 在低 SNR 大 `m` 下数值病态 | 中：离散异常值污染 bias | 中 | 小奇异值置零 + 置零计数进入 `diagnostics`；报告 `cond(Σ̄)` 分布 |
| **R7** | 固定初相位导致偏差结论为特例 | 中：结论不可推广 | 中 | 初相位每次实现随机化（`algorithm-spec.md` §2.5），并在结果中声明期望的定义域 |
| **R8** | `X`、`Y` 独立加噪（非单条轨迹）破坏 EIV 结构 | 高：与原文不可比 | 低（已在规格中规避） | 规格强制 `noise_mode = "trajectory"`；对照组需显式标注 |
| **R9** | 阻尼过大导致窗尾模态被噪声淹没 | 中：低频/弱模态偏差被高估 | 低 | 设计约束 3（窗内幅度衰减 ≥ 30%）以断言形式强制 |
| **R10** | 结论被过度推广到非线性系统 / 有色噪声 | 高（学术风险） | 中 | 报告必须显式声明认知边界（本文件 §2.3） |

| **R11** | **实值通道降偏收益弱、且偏差低于检测下限** | 中：该通道可能无法支撑"TDMD 有效"的结论 | **已转化为设计约束** | 实测：降偏 10–29%（复值 48–92%）。更关键的量化结论是**偏差可分辨性**——见 `algorithm-spec.md` §7.1 实测标定表。已处置：① 偏差可分辨组下移到 `SNR ∈ {0,−5,−10} dB`；② 高 SNR 组按 §6 规则**只报上界**；③ 实值通道 T11 阈值放宽至 `≤ 0.85` 且以复值通道达标为前提 |
| **R14** | **偏差在计划 SNR 档位不可分辨**（原设计 SNR=20/10/5 dB 下需 `J` 达 10⁴–10⁵） | 高：核心假设 H1/H2/H5 无法检验 | **已发生并已处置** | 实测标定（`tmp/scan_lean.py`）显示所需 `J` 随 SNR 约按 `10^(SNR/10)` 变化。已把偏差可分辨组下移到 0/−5/−10 dB（需 `J` ≤ 1.7e3），高 SNR 档保留但仅报偏差上界。详见 ADR-011 |
| **R15** | **性能异常导致可行性误判**（BLAS 线程超额订阅） | 高：曾据此误判项目需数十小时 | **已发生并已处置** | 128×200 复数 SVD：单线程 5.27 ms vs 默认 70.5 ms，**差 13 倍**。已固化为仓库根 `conftest.py` 的线程锁定。详见 ADR-010 |
| **R12** | **T11 判据缺乏可信标定基准**（自造"错误变体"可能是等价变形） | 高：无法确认实现正确性 | **已发生并已闭环** | 分歧已查明：两套测试台各测了不同变体，结论都正确。自造的 `U1⁺U2` 实测与正确实现特征值等价（差 ~1e-15），不能作反例；改用 `U1*U2`（在原文算例上偏差比 12 倍）作负对照。T11 已通过标定并落地为测试。**规格层面已确立原则：自造变体不得直接充当反例，须用原文算例作基准** |
| **R13** | **三条设计约束处于警戒带**（C3/C4/C6） | 低：影响解读而非正确性 | **已确认发生** | C3 模态 2 衰减 0.333（阈值 0.30）、C4 模态 1 恰好 3 周期、C6 模态能量比 1.594。缓解：① 结果报告必须显式披露三条警戒；② `m = 50` 只用于方法间相对比较；③ T14 断言验证警戒确实被触发 |

## 9. 决策记录（ADR）

以下决策已由项目方自主裁定并生效，不再作为待确认事项挂起。**每条决策均记录依据与可推翻条件**——决策可改，但必须给出新依据。

### ADR-001 · 采用 Total DMD 作为 TDMD 的定义

- **决策**：`TDMD = Total DMD`（Hemati, Rowley, Deem & Cattafesta, *TCFD* 31(4):349–368, 2017；arXiv:1502.03854）。
- **依据**：其偏差来源定位（第一阶段子空间投影的非对称处理）与立项描述完全吻合；另有同名方法 *Two-stage Difference Mode Decomposition*（*Measurement* 2024，轴承故障诊断），与偏差-方差理论无关，已排除。
- **可推翻条件**：若提出方另有明确文献指向，须重新确认。

### ADR-002 · 实验三重新定义为方案 3A

- **决策**：实验三采用**方案 3A（秩估计对噪声水平的敏感性）**；3B（正则化 TDMD）、3C（噪声结构失配）列为**可选扩展**，仅在 3A 完成后按剩余预算决定。
- **依据**：原版 TDMD 不含噪声水平输入参数，立项第 3 条在原文算法上无挂钩（三条独立支撑见 `algorithm-spec.md` §5.4）。秩估计 `r̂(σ̂)` 是 `σ̂` 在 TDMD 流程中**唯一自然且必经**的入口，方案 3A 既保留原始研究意图，又不引入新的算法变体。
- **可推翻条件**：若 3A 显示秩估计对 `σ̂` 极不敏感（鲁棒区间极宽），说明该风险实际不存在，可转向 3B 以获取增量贡献。

### ADR-003 · 采用推荐仿真参数

- **决策**：`f_s = 200 Hz`，`(f_1, f_2) = (12.0, 17.5) Hz`，`(ζ_1, ζ_2) = (0.005, 0.004)`，`n = 64`；实值通道 `r = 4`，复值通道 `r = 2`。
- **依据**：六条设计约束已数值校验通过。其中 C3（模态 2 衰减 0.333）、C4（模态 1 恰 3 周期）、C6（模态能量比 1.594）**处于警戒带但不越界**，已在风险 R13 登记并规定披露要求。
- **可推翻条件**：若目标应用有既定的频率/采样率场景，应以目标场景为准并重算全部约束。

### ADR-004 · 实值通道改用实 LTI 状态空间实现

- **决策**：实值通道的信号由 4 维实 LTI 状态空间 + 观测矩阵生成，**不使用** `Σ v_k cos(ω_d t+φ_k)e^{-ζωt}` 的直接叠加式。
- **依据**：后者使 `Y = A X` 不精确成立，任何秩的 DMD 都无法恢复真值。实测该写法下无噪 DMD 频率最大相对误差达 **7.3**（完全失败），改用状态空间形式后降至 **8.1e-16**。
- **可推翻条件**：无。这是正确性问题，不是取舍。

### ADR-005 · 噪声采用单条轨迹模型

- **决策**：`noise_mode = "trajectory"`，`X` 与 `Y` 的噪声在列方向重叠。
- **依据**：物理上传感器记录的是连续轨迹，`X`/`Y` 只是相邻窗口。这正是 DMD 偏差的真实机制，也是 TLS 处理"两侧都有噪声"的实际结构。
- **可推翻条件**：仅当需要与采用独立加噪的文献对比时，作为显式标注的对照组。

### ADR-006 · `J = 5000`（主）／`20000`（关键点）

- **决策**：见 `algorithm-spec.md` §7.1。主网格 `J = 5000`，实验二关键结论点 `J = 20000`，探索网格 `J = 1000`。
- **依据**：统计功效公式 `J > 15.37·(std/|bias|)²`，代入**实测**的 `|bias|/std` 比值反推。原 `J = 2000` 对实值通道不足。
- **可推翻条件**：算力受限时可降，但必须重算 `δ_min` 并如实标注偏差分辨能力的下降。**实验二不建议降**——它占总工时约 2/3，但恰是精度要求最高的一环。

### ADR-007 · 双通道交叉验证判据由"同量级"改为 X1–X3

- **决策**：见 `experiment-protocol.md` §1.1。
- **依据**：实测两通道偏差量级相差约一个数量级，原判据不可达。X3 把"分歧"从缺陷信号重新定义为**待解释的现象**。
- **可推翻条件**：若查明实值通道收益弱系构造缺陷所致（风险 R11 的机制解释指向实现问题），则恢复原判据。

### ADR-008 · 验收门 G3 由无噪判据升级为含噪判别判据

- **决策**：G3 由"T2/T3 通过"升级为"G3-a + G3-b（T11）+ G3-c 形状断言"。
- **依据**：实测证伪了原设计——误用左奇异向量时无噪判据仍全部通过（误差 `8.9e-16`）。
- **可推翻条件**：无。这是判别力的硬约束。

### ADR-010 · 锁定 BLAS 单线程

- **决策**：仓库根 `conftest.py` 与 `tests/conftest.py` 在所有 numpy 导入之前设置 `OPENBLAS_NUM_THREADS=1`（及 `OMP_NUM_THREADS`、`MKL_NUM_THREADS`）。所有实验脚本入口须同样处理。
- **依据**：本项目矩阵规模小（`2n × m ≤ 128 × 500`），OpenBLAS 多线程调度开销远大于计算。实测 128×200 复数 SVD：单线程 5.27 ms，默认 70.50 ms，**差 13 倍**；单次完整实现 191 ms → 16.8 ms。
- **可推翻条件**：若将来矩阵规模增大到单次运算 > 100 ms，应重新评估线程数（大矩阵下单线程会成为瓶颈）。

### ADR-011 · 偏差可分辨组下移到低 SNR 区

- **决策**：把用于检验偏差类假设（H1/H2/H5/H7）的 SNR 档位从 `{20, 10, 5}` dB 调整为 **`{0, −5, −10}` dB**；原高 SNR 档保留，但偏差**只报上界**（用于支撑"高 SNR 时标准 DMD 够用"这一实用结论）。
- **依据**：实测标定（`algorithm-spec.md` §7.1）显示所需 `J` 约按 `10^(SNR/10)` 变化。在 SNR=10 dB 处即使最优情形也需 `J ≈ 1.5e5`，而在 SNR ≤ 0 dB 处降至 `J ≈ 1.7e3`。**不是实现问题，而是当前测试床（近单位模、良态、高信噪比）的固有性质**——DMD 的噪声偏差本就很小的。
- **可推翻条件**：若目标应用要求在高 SNR 下刻画偏差，则须改用其他放大偏差的手段（更强模态不平衡、更少的空间通道、更接近的模态间隔），并重新标定。

### ADR-012 · 放宽 C6 的构造目标，把幅度比作为实验因子

- **决策**：C6 的**硬约束**保持 `E_max/E_min ∈ [0.5, 2.0]` 不变；**构造目标**从"精确平衡（比值 1.0）"改为"比值约 1.5–2.0"。同时把模态幅度比列为敏感性分析的一个显式轴。
- **依据**：实测非平衡幅度在 SNR ≤ 5 dB 区间使所需 `J` 降低 3.6–8 倍（弱模态的相对偏差显著更大）。强制精确平衡虽让两模态统计可比，却把待测效应也一并压小，反而削弱实验的可分辨性。
- **副作用与处置**：平衡态仍须作为一路对照保留（C6 逐实现精确成立已由测试固化），用于说明幅度比对结论的影响。
- **可推翻条件**：若正式实验显示幅度比对结论无实质影响，可回到单一比值以简化设计。

### ADR-009 · 项目内虚拟环境

- **决策**：项目虚拟环境位于 `.venv/`，Python 3.12.10，依赖 `numpy / scipy / matplotlib / pandas / pyyaml / pytest`。
- **依据**：依赖隔离，避免污染系统环境；`.venv/` 不入版本库。
- **可推翻条件**：无。

**但必须说明两点保留**：

1. 上述"避免的返工"是**反事实推算**，不是实测数据。它的意义在于说明量级，而非精确收益。
2. **预验证尚未完成。** 含噪部分存在未决问题（§8.2.1），目前**不能**作为实现的正确性依据。也就是说，已经花掉的 0.25 人日买到了 4 项确定结论，但第 5 项（T11 标定）正是当前阻塞 M3 的任务，仍需投入（已计入 §10.2 的 M3 行）。

**结论**：预验证**有价值，且价值主要来自"证伪"而非"证实"**——它推翻了三条原有论断，避免了在一个错误判据体系下跑到项目末期。**性价比成立的前提是它发生在 M0 之前**；同样的 2 小时若放在 M5 之后，价值将接近于零。
