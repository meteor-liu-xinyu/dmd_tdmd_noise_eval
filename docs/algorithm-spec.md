## 1. 符号与约定

### 1.1 通用符号

| 符号 | 含义 | 本项目取值 |
|---|---|---|
| `n` | 状态维数 / 传感器通道数 | 64（主实验） |
| `m` | **快照数**（快照矩阵列数），即立项所述"样本量" | 50 … 500 |
| `r` | 截断秩（保留模态数） | 4（实值）；2（复值解析信号） |
| `r_true` | 系统真实模态数 | 4（实值）；2（复值） |
| `f_i` | 第 `i` 阶模态频率（Hz） | 见 §2.2 |
| `Δt` | 采样间隔，`Δt = 1/f_s` | `f_s = 200 Hz` → `Δt = 5 ms` |
| `λ_i` | 连续时间特征值，`λ_i = -ζ_i ω_i + j ω_{d,i}` | — |
| `μ_i` | 离散时间特征值，`μ_i = exp(λ_i Δt)` | — |
| `σ` | 加性噪声的逐元素标准差 | 由 SNR 反解，见 §3 |
| `J` | 蒙特卡洛实现次数（noise realizations） | 主实验 2000 |

> **术语澄清（立项勘误）**：立项文档第 2 条写作 "TDMD 的偏差是否按理论预测的 O(1/√n) 速率下降"。在 DMD 文献中 `n` 固定用于表示**状态维数**，而"样本量"指**快照数**。本项目**统一用 `m` 表示快照数**，理论速率表述为 `O(1/√m)`（针对标准差/RMSE），`O(1/m)`（针对 MSE）。全文档不得再用 `n` 表示样本量。

### 1.2 算子与矩阵

| 符号 | 含义 |
|---|---|
| `X` | 快照矩阵，`X = [x_1, …, x_m] ∈ ℝ^{n×m}`（或 ℂ^{n×m}） |
| `Y` | 移位快照矩阵，`Y = [x_2, …, x_{m+1}] ∈ ℝ^{n×m}` |
| `X̄, Ȳ` | 噪声自由（真值）快照矩阵 |
| `ΔX, ΔY` | 加性噪声，`X = X̄ + ΔX`，`Y = Ȳ + ΔY` |
| `Z` | 增广快照矩阵，`Z = [X ; Y] ∈ ℝ^{2n×m}`（行堆叠） |
| `Ã` | 降维后的离散算子，`Ã ∈ ℂ^{r×r}` |
| `P_M` | 到 `M` 值域的正交投影算子 |
| `·⁺` | Moore–Penrose 伪逆 |
| `·ᵀ, ·*` | 转置、共轭转置 |

## 2. 仿真器规格

### 2.1 真实系统模型

系统为双模态阻尼振荡。**两个通道必须用两种不同的构造方式，二者不可互换**——这是本规格中最容易出错的地方，原因见 §2.1.3。

#### 2.1.1 实值通道（主通道）：实 LTI 状态空间实现

4 维实状态（两个复共轭对），`n` 通道观测：

```
μ_k = exp(λ_k Δt),     λ_k = -ζ_k ω_k + j ω_k √(1 - ζ_k²),   k = 1, 2
B_k = [[ Re μ_k ,  Im μ_k ],
       [ -Im μ_k,   Re μ_k ]]              # 2×2 实块，特征值为 {μ_k, μ̄_k}
A_z = blockdiag(B_1, B_2) ∈ ℝ^{4×4}        # 真实状态转移
z_{j+1} = A_z z_j
x_j = C z_j,             C ∈ ℝ^{n×4}       # 观测矩阵，随机满秩
X = C · [z_0 … z_{m-1}],   Y = C · [z_1 … z_m]
```

由此 `Y = C A_z [z_0 … z_{m-1}] = (C A_z C⁺) X`，即 **`Y = Ã_true X` 精确成立**，其中 `spec(C A_z C⁺) = spec(A_z) = {μ_1, μ̄_1, μ_2, μ̄_2}`。故 `r_true = 4`。

> 这对应物理上"传感器观测二阶机械系统的位移与速度组合量"的情形。**不允许**用 `x(t) = Σ_k v_k cos(ω_{d,k}t+φ_k) e^{-ζ_kω_k t}` 这种写法，理由见 §2.1.3。

#### 2.1.2 复值通道（对照通道）：解析信号

```
x_j = Σ_{k=1}^{2} c_k v_k μ_k^j ,    c_k ∈ ℂ,  v_k ∈ ℂⁿ
X = V diag(c) [μ_k^{j-1}],   Y = X 经同一生成式右移一列
```

由此 `Y = Ã_true X` 同样精确成立，`Ã_true = V diag(μ) V⁺` → `r_true = 2`。该通道与原始文献（Hemati et al. 2017）的算例设定一致。

#### 2.1.3 时延嵌入通道（Hankel，单测点场景）

对应真实部署中"**少量测点 + 时延构造虚拟通道**"的形态，是本项目的**主通道之一**（ADR-013）。

```
u_j = Σ_k c_k μ_k^j                    单测点标量（解析）序列，j = 0..m+L-1
X[i, j] = u_{i+j},  Y[i, j] = u_{i+j+1},   i = 0..L-1,  j = 0..m-1
```

嵌入维数 `L` 即该通道的"空间维数 `n`"。无噪时 `rank(Z) = n_modes`，且 `Y = A_true X` 精确成立
（已由测试 T4/T1 固化）。`r_true = n_modes = 2`（复值解析）。

**为什么需要它**：立项的应用场景是"从传感器数据算振动频率"，真实部署通常是
**1–3 个测点**。多通道形式（`n` 个独立传感器）在 `n` 小时与它等价，但时延嵌入才是
单测点下的标准做法。两者对 `n` 依赖的机理不同，须分别刻画。

**实测特性（重要）**：`L` 过小时估计严重退化。实测（SNR=10 dB，`m=200`）：

| `L` | 无噪 DMD | 含噪 DMD | 含噪 TDMD | 结论 |
|---|---|---|---|---|
| 4 | 精确 | 7.65 / 14.86（真值 12 / 17.5） | 8.26 / 16.36 | 严重退化 |
| 8 | 精确 | 14.74 / 15.41（**两模态合并**） | 12.27 / 17.82 | 分辨率失效 |
| 16 | 精确 | 12.05 / 17.47 | 12.00 / 17.53 | 可用 |

即**无噪精确但含噪严重退化**——这正是偏差问题的极端形态。`L ≤ 8` 时须把
**配对/分辨率失效率**作为一等指标报告（见 §4.4），不得只报存活样本的统计量。

#### 2.1.4 为什么实值通道必须用状态空间形式

若实值信号写作

```
x(t) = Σ_k a_k · v_k · exp(-ζ_k ω_k t) · cos(ω_{d,k} t + φ_k),   v_k ∈ ℝⁿ
```

则 `x_j` 恒落在 `span{v_1, v_2}` 内，快照矩阵 `rank(X) ≤ 2`（每个模态只激发**一个**实空间方向）。但 `x_{j+1}` 相对 `x_j` 的比值 `g_k(t_{j+1})/g_k(t_j)` 随时间变化，**不存在**与之匹配的固定线性算子，即 `Y = A X` **不精确成立**、任何秩的 DMD 都无法精确恢复真值。

**数值证据（已验证）**：采用该错误写法时，无噪 DMD 恢复频率的最大相对误差为 `7.3`（完全失败），判据 T1 直接不通过；改用 §2.1.1 的状态空间形式后，误差降至 `8.1e-16`。

`rank(X) = 4` 的来源是：每个阻尼正弦在实空间需要**两个**独立空间方向（对应 `cos`/`sin` 两个正交相位分量），否则该模态在快照空间中不构成不变子空间。

### 2.2 参数取值与设计约束

推荐初值：

| 参数 | 值 |
|---|---|
| `f_s` | 200 Hz |
| `f_1` | 12.0 Hz |
| `f_2` | 17.5 Hz |
| `ζ_1, ζ_2` | 0.005, 0.004 |
| `n` | 64 |
| `C` 的生成 | 随机满秩；**无需按列归一化**（归一化被实测证无效，见 C6） |
| `c_k`（复通道） | 等幅，`|c_1| = |c_2|`，相位随机 |

**六条设计约束**：实现时写入 `src/dmdnoise/sim/oscillator.py`。分两档处理——**硬约束**（违反即抛异常）与**警戒带**（进入即输出 `logging.warning` 并写入结果元数据）。

| # | 约束 | 表达式 | 硬阈值 | 警戒带 | 当前取值 | 状态 |
|---|---|---|---|---|---|---|
| C1 | 避开频率边界 | `0.05 ≤ f_i/f_s ≤ 0.45` | 硬 | — | 0.0600 / 0.0875 | PASS |
| C2 | 模态可分辨性 | `\|f_1-f_2\| / min(f_1,f_2) ≥ 0.25` | 硬 | `[0.25, 0.30)` | 0.4583 | PASS |
| C3 | 窗内幅度衰减 | `exp(-ζ_k ω_k m_max Δt) ≥ 0.30` | 硬 | `[0.30, 0.40)` | 0.3897 / **0.3330** | PASS（模态 2 余量仅 11%，**触发警戒**） |
| C4 | 最少周期数 | `min_k f_k · m_min · Δt ≥ 3` | 硬 | `[3.0, 3.5)` | **3.00** / 4.38 | PASS（模态 1 恰在边界，**触发警戒**） |
| C5 | 空间维数充分 | `n ≥ r_max`（硬）；建议 `n ≥ 2·r_max` | 硬 `n ≥ r_max` | `n < 2·r_max` | 见下 | PASS |
| C5b | 嵌入维数充分 | `min(L) ≥ r_complex` | 硬 | `L < 2·r_complex` | 4 ≥ 2 | PASS |
| C6 | **模态可观测性平衡** | `0.5 ≤ E_1/E_2 ≤ 2.0`，`E_k = ‖C[:, mode_k块] · z_{mode_k} 轨迹‖_F` | 硬 | `[0.5,0.7)∪(1.4,2.0]` | 1.594 | PASS（**触发警戒**） |

**C6 的必要性（实测依据）**：若两模态的可观测能量相差过大，弱模态的偏差会被噪声完全淹没、且模态间统计不可比。实测在未平衡时两模态 `std` 相差 1.2 倍、`bias/std` 比值相差 **5.4 倍**（模态 1 为 0.037，模态 2 为 0.199），意味着同一实验对不同模态的偏差分辨能力完全不同。

**C6 的达成方式（实测教训）**：**对观测矩阵 `C` 按模态块归一化是无效的**——实测显示该操作把逐模态能量从 `[173.9, 109.1]` 等比缩放到 `[87.9, 56.5]`，比值仍为 1.594，`bias/std` 比值几乎不变（0.037→0.037、0.199→0.199）。

原因：模态能量的不平衡来自**初状态 `z_0` 在各模态上的投影幅度**，而非 `C` 的列尺度。正确做法是**在特征基下构造 `z_0` 并平衡各模态分量**：

```
z_0 = V · α,   V = [Re v_1, Im v_1, Re v_2, Im v_2]（A_z 的实特征基）
α 中的两个模态分量按 |α_mode1| : |α_mode2| 调节，使 E_1 ≈ E_2
```

实现时以 `E_1/E_2 ∈ [0.9, 1.1]` 为构造目标、以 `[0.5, 2.0]` 为硬约束。

**C3、C4、C6 三条均触发警戒**，这是当前参数集的固有特征，须在结果解读中一并说明，不得静默忽略。

**C3 与 C4 的边界说明**：这两条是当前参数下**唯二处于边界附近**的约束，含义如下：

- C3 触发警戒：在最长窗 `m_max = 500` 处，模态 2 的幅度已衰减到初值的 33.3%。这不影响正确性，但意味着**窗尾数据对模态 2 的贡献显著减弱**，其有效样本量小于名义 `m`。结果解读时必须注意。
- C4 触发警戒：`m_min = 50` 处低频模态恰好只有 3 个周期，处于频率分辨率的**理论下限**。因此 **`m = 50` 的网格点应仅用于"方法间相对比较"，不得单独作为绝对频率精度的基准**。这一条必须写入结果说明。

> 若后续需要消除上述两处边界，可将 `ζ` 降至 `(0.004, 0.003)`（C3 抬升至 0.471 / 0.438）。该调整属于参数评审事项，改动后须重跑全部基线验证。

### 2.3 真值频率基准（易错）

DMD 估计的是**阻尼频率** `ω_{d,k} = ω_k √(1-ζ_k²)`，而非无阻尼固有频率 `ω_k`。二者相对差为

```
(ω_k - ω_{d,k}) / ω_k = 1 - √(1-ζ_k²) ≈ ζ_k² / 2
```

当前参数下 `ζ_1 = 0.005` → 相对差 **8.0e-6**。

**这个偏移量大于 SNR = 20 dB 档下实测的 DMD 偏差量级**（实测 `|bias| ≈ 3.7e-5` 相对值，见 §11）。因此：

```
f_i^true := ω_{d,i} / (2π) = f_i · √(1 - ζ_i²)      ← 指标定义中的真值，必须用此式
```

**禁止**用名义 `f_i`（12.0 / 17.5 Hz）作为偏差计算基准。实现时由 `A_z` 或 `μ_k` 反解真值，而非从配置读取名义频率。

### 2.4 随机源与种子管理

以下随机量必须在每次实现中独立抽取，且各自使用从 `SeedSequence` 派生的独立子流：

| 随机量 | 分布 | 随实现变化 | 说明 |
|---|---|---|---|
| `C`（观测矩阵） | 随机满秩 | **否**（固定） | 保证问题定义一致 |
| `z_0` 的**模与模态配比** | 由 C6 约束确定 | **否**（固定） | 保证模态可观测性平衡 |
| `z_0` 的**相位方向** | `U(0, 2π)` | **是** | 即初相位随机化，见 §2.5 |
| 噪声 `ε` | 见 §3 | **是** | — |

`C` 与 `z_0` 的模固定，是为了让所有实现面对同一个"系统实例"，从而把统计变异完全归因于噪声与初相位；否则"偏差"会混入系统实例间的差异。

**实现要求**：把 `z_0` 分解为"固定模 × 随机相位"两部分——在特征基下保留 §2.1.1 生成时确定的模态配比，仅对每个模态施加随机旋转。禁止在每次实现中整体重抽 `z_0`，那会同时改变模态配比、破坏 C6。

### 2.5 初相位与随机化策略

**主实验：初相位每次实现独立随机。**

- **实值通道**：按 §2.4，对固定的 `z_0` 模在各个模态块上施加独立的随机 2×2 旋转（即绕相位角随机化），配比不变。等价地，也可对 `C` 的每个模态块施加随机旋转——两者数学等价，实现时取其一并在代码注释中说明。
- **复值通道**：`c_k = |c_k| e^{jφ_k}`，`φ_k ~ U(0, 2π)` 每次实现独立抽取，`|c_k|` 固定。

理由：若固定相位、仅随机化噪声，则测得的"偏差"是对单一相位取期望的结果。DMD 频率偏差在相位空间上不是常数，固定相位可能得到特例结论。随机化相位使 `E[f̂]` 成为对"噪声 × 初相"的联合期望。

此选择必须在结果文档中显式声明，因为"偏差"的定义依赖它。

## 3. 噪声模型与 SNR 定义

### 3.1 噪声注入方式（关键实现细节）

**采用单条噪声轨迹模型**，而非对 `X` 与 `Y` 独立加噪：

```
ε ∈ ℝ^{n×(m+1)}，各元素独立同分布 ~ 𝒩(0, σ²)
X = X̄ + ε[:, 1:m]
Y = Ȳ + ε[:, 2:m+1]
```

**理由**：物理上传感器记录的是一条连续含噪轨迹 `u(t)`，`X` 与 `Y` 只是同一条轨迹的相邻窗口，因此 `ΔX` 与 `ΔY` 在列方向**高度重叠**。这正是 DMD 偏差产生的真实机制，也是 TLS 处理"两侧都有噪声"的实际结构。

若对 `X`、`Y` 独立加噪，则改变误差变量模型的结构，结论不可与原文对比。因此：

- **主实验**：单条噪声轨迹（`noise_mode = "trajectory"`）
- **对照实验**（可选，用于说明模型选择的影响）：独立加噪（`noise_mode = "independent"`）

该配置项必须进入结果元数据。

### 3.2 SNR 定义

以 F-范数为能量度量，采用**聚合 SNR**：

```
SNR_dB = 10 log₁₀( ‖X̄‖_F² / E[‖ΔX‖_F²] )
```

其中 `E[‖ΔX‖_F²] = n · m · σ²`，故噪声标准差由下式反解：

```
σ = ‖X̄‖_F / √( n · m · 10^(SNR_dB / 10) )
```

同时报告**逐元素噪声比**，便于与其他文献横向比较：

```
ε := σ / rms(X̄),    rms(X̄) = ‖X̄‖_F / √(n·m)
⟹  SNR_dB = -20 log₁₀(ε)
```

**必须记录的两点**：

1. 本定义是**全矩阵聚合 SNR**，不是逐模态 SNR。当两模态幅度不等或衰减速率不同时，各模态的局部 SNR 不同。因此仿真器需额外输出**逐模态局部 SNR** 供结果解读。
2. 在本定义下 `σ` 与 `m` 无关（信号与噪声能量同比例增长），故"固定 SNR 增加 `m`"是良定义的实验设计。这正是实验二所需。

> 若采用"固定绝对 `σ`、增加 `m`"的替代约定，需在结果中标明 `snr_convention = "fixed_sigma"`，不可与主实验混图。

## 4. 标准 DMD 规格

### 4.1 两阶段视角（偏差的定位）

标准 DMD 可分解为：**(1) 子空间投影 → (2) 算子识别**。

**第一阶段（投影）**：

```
P_{X*} = U_r U_r*          # 基于 X 的左奇异向量
Ȳ ← Y P_{X*}
X̄ ← X P_{X*} = X           # 由构造自动满足
```

**偏差来源**：第一步只对 `Y` 做"纠错"，而把 `X` 当作精确值。即 `X` 中的噪声被完全忽略，`X` 与 `Y` 被**非对称处理**。这就是系统性偏差的位置——它来自子空间本身被噪声污染，而不是来自第二阶段的最小二乘。

### 4.2 算法

```
算法 A1 — 标准 DMD
────────────────────────────────────────────────────────
输入: X, Y ∈ ℂ^{n×m}, 截断秩 r
输出: {(f_i, μ_i, φ_i)}_{i=1..r}

1. U, Σ, V* ← SVD(X)                       # 经济型 SVD
2. 截断: U_r ← U[:, :r], Σ_r ← Σ[:r], V_r ← V[:, :r]
3. 投影: Ȳ ← Y V_r V_r*                    # 仅对 Y 纠错（偏差来源）
4. SVD:  X̄ ← Ū Σ̄ V̄*                       # X̄ = X V_r V_r*
5. 算子:  Ã ← Ū* Ȳ V̄ Σ̄^{-1}                (r×r)
6. 特征分解: Ã W = W Λ
7. 频率:  f_i ← arg(Λ_ii) / (2π Δt)
8. 模态:  φ_i ← Ū w_i
────────────────────────────────────────────────────────
```

> 第 3–5 步在构造上等价于经典 DMD 形式 `Ã = U_r* Y V_r Σ_r^{-1}`。保留两阶段写法是为了让 TDMD 的差异在代码中**逐行可见**，便于代码评审。

### 4.3 频率提取与缠绕处理

`arg(·) ∈ (-π, π]`，对应 `f ∈ (-f_s/2, f_s/2]`。**必须**：

- 用 `angle(μ)` 而非 `imag(log(μ))` 的隐式主值展开；
- 对返回频率取绝对值并按升序排序；
- 若 `f_i` 落在 `(0.45, 1.0)·f_s/2` 区间，输出警告标志 `near_nyquist=True`，该实现不计入偏差统计（防缠绕造成的假偏差）。

模态配对：将估计频率按升序排序后，与真实频率升序序列按索引配对。两模态间隔已由约束 2 保证足够大，排序配对在实验噪声范围内是稳定的；实现中仍须记录**配对失败计数**（若 `|f̂_i - f_i^true| > 0.4|f_1 - f_2|` 判为配错），配错样本从统计中剔除并单独报告比例。

---

### 4.4 ★ 配对失效率与选择偏差（强制规则）

配对失败（模态合并 / 配错）的样本必须剔除；但**当失败率较高时，剔除本身会引入偏差**：

> 存活样本是"估计恰好落在真值附近"的实现集合。按配对成功筛选，
> 等价于对被估计量施加了一个**以真值为中心的截断**，
> 会把测得的偏差系统性**压低**，并虚增两法的"降偏效果"。

**实测证据**：SNR=−5 dB、`n=8`、`m=200`、`J=200` 下，标准 DMD 的配对结局为

| 结局 | 次数 / 200 |
|---|---|
| 配错（`\|Δf\| > 0.4×` 模态间隔） | 105 |
| 模态数不足（两模态被估计成一个） | 26 |
| 配对成功 | **69** |

即**失败率高达 65%**，此时"存活样本的偏差"完全不可信。

**强制规则**：

| 配对失败率 | 处置 |
|---|---|
| `≤ 20%` | 可报告偏差点估计；失败率须随结果一并披露 |
| `> 20%` | **不得报告偏差**，只能标注"配对失效率过高（选择偏差风险）" |

该门槛已落地为 `PAIR_FAIL_GATE = 0.20`（`experiments/exp1_bias_variance.py`），
并写入 `reportable` 字段。**工作点必须选在失败率低的区域**——
提高 `n` / 降低 SNR 都可能把失败率推高，须先核实再定实验点。

> 这也是 T11 判别性测试的工作点由 `n=8, SNR=−5 dB` 改为 **`n=4, SNR=10 dB`** 的原因：
> 后者 DMD 偏差达 4.5%（`J≈1` 即可分辨）且失败率低，比值才可信。

## 5. TDMD（Total DMD）规格

### 5.1 核心差异

TDMD 的唯一改动在**第一阶段投影**：用**增广快照矩阵 `Z = [X ; Y]`** 的**右奇异向量**构造投影，使 `X` 与 `Y` 被**对称处理**。

```
P_{Z_r*} = Ṽ_r Ṽ_r*        # 注意：右奇异向量，不是左奇异向量
```

### 5.2 算法

```
算法 A2 — TDMD
────────────────────────────────────────────────────────
输入: X, Y ∈ ℂ^{n×m}, 截断秩 r
输出: {(f_i, μ_i, φ_i)}_{i=1..r}

1. 增广:  Z ← [X ; Y]                       # ∈ ℂ^{2n×m}，行堆叠
2. SVD:   Ũ, Σ̃, Ṽ* ← SVD(Z)
3. 截断:  Ṽ_r ← Ṽ[:, :r]                     # 关键：取右奇异向量
4. 投影:  X̄ ← X Ṽ_r Ṽ_r*                     # X 与 Y 同等对待
          Ȳ ← Y Ṽ_r Ṽ_r*
5. SVD:   X̄ ← Ū Σ̄ V̄*
6. 算子:  Ã ← Ū* Ȳ V̄ Σ̄^{-1}
7. 特征分解、频率提取、模态计算同算法 A1 第 6–8 步
────────────────────────────────────────────────────────
```

### 5.3 退化判据（必要但**不充分**）

| 判据 | 内容 | 容差 | 预验证 |
|---|---|---|---|
| D1 | 无噪时 TDMD 退化为标准 DMD | `‖Ã_TDMD - Ã_DMD‖_F / ‖Ã_DMD‖_F < 1e-10` | ✅ 1.30e-15（实）/ 4.40e-16（复） |
| D2 | 无噪时两法均精确恢复真模态 | `max_i \|f̂_i - f_i^true\| / f_i^true < 1e-10` | ✅ 8.1e-16 / 4.4e-16 |

D1 对应原文声明 *the resulting unbiased and noise-aware total DMD formulation reduces to standard DMD in the absence of snapshot errors*。

> ⚠️ **D1/D2 是必要条件，但不是充分条件。** 实测证明，投影子空间取错（误用 `Z` 的左奇异向量）时这两条判据**仍然全部通过**（误差 `8.9e-16`），因为无噪时 `rank(Z) = r` 满秩，任何基于 `Z` 的正交分解都张成同一子空间并给出精确算子。
>
> **因此必须补充 §8.2 的含噪判别判据 T11。** 仅通过 D1/D2 而未经 T11 验证的实现，不得进入实验阶段。

### 5.4 关于"噪声估计"的规格说明（对应实验三）

**规格结论：原版 TDMD（算法 A2）不含任何噪声水平输入参数。**

该结论有三条独立支撑：

1. **原文层面**：TDMD 算法步骤中不含 σ；文中对 "noise-aware" 的用法是描述 TLS 框架本身，原文明确写道 *While the term noise-robust is often used to describe (regularized) total-least-squares problems in the literature, in the remainder, we choose to use the term noise-aware to emphasize the need for algorithmic techniques with greater computational robustness... Such issues are outside the scope of this study, but are the focus of ongoing work.*
2. **代数层面**：设对增广矩阵做**行方向**噪声归一化 `Z' = D Z`（`D = diag(I_n/σ_X, I_n/σ_Y)`）。因 `D` 可逆对角，`Z'` 与 `Z` 的**行空间相同**，故截断投影子空间 `span(Ṽ_r)` 相同，`Ṽ_r Ṽ_r* = V_r V_r*`，投影后的 `X̄, Ȳ` 逐元素相同，`Ã` 完全相同。**即行方向噪声比加权对 TDMD 结果无影响**。
3. **数值层面**：由 D1 判据，`σ = 0` 时 TDMD 已退化为 DMD；若存在 `σ` 的显式入口，则 `σ̂ → 0` 时结果应连续趋于 DMD，而算法 A2 本身不含该自由参数。

因此，若实验三要考察"噪声估计不准"的影响，必须**先定义 `σ̂` 究竟进入算法的哪个环节**。三个可行方案见 `docs/experiment-protocol.md` §4.2–§4.4，其中方案 3A（秩估计敏感性）改动最小、可辩护性最强，**已裁定采用**（见 `docs/implementation-plan.md` ADR-002）。`σ̂` 的秩估计器精确规格见本文件 §10。

## 6. 指标定义

设方法 `M ∈ {DMD, TDMD}`，模态 `i`，快照数 `m`，SNR 档位，第 `j ∈ {1..J}` 次实现给出估计 `f̂_{i,M}^{(j)}(m)`。

| 指标 | 定义 | 说明 |
|---|---|---|
| **偏差** `bias_i` | `(1/J) Σ_j f̂_i^{(j)} - f_i^true` | 期望意义上的系统性误差 |
| **标准差** `std_i` | `√( (1/(J-1)) Σ_j (f̂_i^{(j)} - f̄_i)² )` | 抖动幅度 |
| **MSE** | `bias_i² + std_i²` | 分解式；等价于 `E[(f̂ - f_true)²]` |
| **RMSE** | `√MSE` | 用于 log-log 斜率拟合 |
| **相对量** | 上述各项 `/ f_i^true` | 以 % 或 ppm 报告 |
| **配对差** | `Δ^{(j)} = f̂_{TDMD}^{(j)} - f̂_{DMD}^{(j)}` | 同一噪声实现，方差消减 |
| **MC 标准误** | `std_i / √J` | 偏差的检测下限 |
| **检测下限** | `δ_min = 1.96 · std_i / √J` | 若 `|bias| < δ_min`，只能报告"与 0 无显著差异" |

**必须报告检测下限。** 在低 SNR 下 TDMD 的真实偏差可能远小于其标准差，此时"偏差 ≈ 0"的正确表述是"偏差在 95% 置信水平下不可与 0 区分，上界为 `δ_min`"，而不是"偏差为零"。这是本项目结论可信度的关键，不可省略。

### 6.1 置信区间的构造规格

协议中多处引用"95% CI"，此处统一规定构造方法。**不同类型统计量用不同方法，不得混用。**

| 统计量 | CI 构造方法 | 理由 |
|---|---|---|
| `bias`（均值） | 正态近似：`bias ± 1.96 · std/√J` | `f̂` 近似高斯；`J ≥ 1000` 时正态近似充分 |
| `std` | **bootstrap**：对 `{f̂^(j)}` 重采样 `B = 10 000` 次，取 `std` 的 2.5% / 97.5% 分位 | `std` 的抽样分布右偏，正态近似在高 SNR 下不准确 |
| `std` 的**比值**（H3） | **配对 bootstrap**：同一重采样索引同时作用于两法的估计序列 | 保持两法的配对结构，得到比值的正确抽样分布 |
| `MSE` 的**比值**（H4） | 配对 bootstrap，同 H3 | 同上 |
| 斜率 `ŝ`（H5–H7） | **跨实现 t 区间**：`ŝ ± t_{0.975,J-1} · std_j(ŝ_j)/√J` | 逐实现拟合后跨实现统计，见 §7.3 |

**配对 bootstrap 的实现要求**：重采样必须按**实现索引**（第 `j` 次）整体重采样，即同时抽取 `f̂_DMD^(j)` 与 `f̂_TDMD^(j)`。**禁止**对两法分别独立重采样——那会破坏公共随机数带来的协方差结构，使比值 CI 偏宽。

**bootstrap 随机源**：使用独立于实验噪声的 `SeedSequence` 子流（`purpose="bootstrap"`），保证 CI 可复现。

### 6.2 配对差与其方差消减效应

定义逐实现的配对差 `Δ^(j) = f̂_TDMD^(j) - f̂_DMD^(j)`。在公共随机数设计下：

```
Var(Δ) = Var(f̂_DMD) + Var(f̂_TDMD) - 2·Cov(f̂_DMD, f̂_TDMD)
```

**必须同时报告 `Var(Δ)` 与两法各自方差之和**，用以量化公共随机数带来的方差消减幅度。若 `Var(Δ)` 并未显著小于方差之和，说明公共随机数设计失效（例如两法实际使用了不同噪声实现），须排查实现缺陷。这是对"配对设计确实生效"的**强制自检项**。

## 7. 蒙特卡洛统计协议

### 7.1 实现次数与统计功效（★ 已由实测重标定）

**分辨条件**：要在 95% 置信下把偏差分辨到其自身量级的 50% 以内，需要

```
1.96 · std/√J  <  |bias| / 2
⟹  J  >  15.37 · ( std / |bias| )²
⟹  可分辨判据：  |bias|/std  >  3.92 / √J
```

#### 7.1.1 实测标定表

由 `tmp/scan_lean.py` 实测（复值通道 `r=2`，`m=200`，`J=1200`，模态 1 = 12 Hz）。
`需J` 为达 50% 相对分辨所需实现次数；✅ 表示该点实测偏差已显著（`|bias| > 1.96·MCSE`）。

**平衡幅度（`E_1 = E_2`，即 C6 目标比值 1.0）**

| SNR | DMD `\|bias\|` | DMD `std` | `\|b\|/std` | DMD 需 `J` | TDMD `\|bias\|` | TDMD 需 `J` |
|---|---|---|---|---|---|---|
| 10 dB | 1.10e-5 | 7.89e-4 | 0.0140 | **78 400** | 3.99e-7 | 6.0e7 |
| 5 dB | 3.03e-5 | 1.74e-3 | 0.0174 | **50 800** | 7.99e-6 | 7.3e5 |
| 0 dB | 未测出 | 4.54e-3 | — | >1e6 | 5.63e-5 | 9.8e4 |
| −5 dB | 8.09e-4 | 1.36e-2 | 0.0595 | **4 340** ✅ | 4.53e-4 | 13 200 |

**非平衡幅度（随机复数系数，`E_1/E_2` 自然分散）**

| SNR | DMD `\|bias\|` | DMD `std` | `\|b\|/std` | DMD 需 `J` | TDMD `\|bias\|` | TDMD 需 `J` |
|---|---|---|---|---|---|---|
| 10 dB | 6.24e-6 | 6.26e-4 | 0.0100 | **154 900** | 7.84e-6 | 9.8e4 |
| 5 dB | 4.37e-5 | 1.32e-3 | 0.0331 | **14 000** | 2.35e-5 | 48 500 |
| 0 dB | 3.08e-4 | 3.26e-3 | 0.0945 | **1 722** ✅ | 1.08e-4 | 13 900 |
| −5 dB | 1.54e-3 | 9.33e-3 | 0.1650 | **564** ✅ | 7.65e-4 | 2 235 ✅ |

#### 7.1.2 由实测得出的三条规律

1. **所需 `J` 随 SNR  按 `10^(SNR/10)` 变化**——每降低 10 dB，所需实现次数减少约一个数量级。这与偏差 `∝ σ²`、标准差 `∝ σ` 的理论标度一致（实测 SNR 10→5 dB 时 DMD 偏差放大 2.75 倍，与 `1.78² = 3.16` 相符）。
2. **SNR ≥ 10 dB 时偏差实际不可分辨**——即使在最优（非平衡）情形也需 `J ≈ 1.5e5`，而实测 `J=1200` 下偏差量级仅与 MC 标准误相当。**这不是实现缺陷，而是当前测试床的固有性质**：近单位模、高信噪比、良态系统的 DMD 噪声偏差本就极小。
3. **模态幅度不平衡对分辨有实质帮助**——在 SNR ≤ 5 dB 区间使所需 `J` 降低 3.6–8 倍（弱模态的相对偏差显著更大）。在 SNR = 10 dB 处该效应被 MC 噪声淹没。

#### 7.1.3 取值决策（已据实修订）

| 用途 | SNR 档位 | `J` | 依据 |
|---|---|---|---|
| **偏差可分辨组（主结果）** | 0 / −5 / −10 dB | 5 000 | 实测需 `J` ≤ 1 722，留 3 倍裕度 |
| **高 SNR 组（偏差只报上界）** | 20 / 10 / 5 dB | 5 000 | 偏差不可分辨，按 §6 规则**只报上界**，不做方法间偏差对比 |
| 实验二 `m` 序列（关键结论点） | −5 dB | 20 000 | 标度律斜率需要高精度 |
| 探索 / 绘图 | 任意 | 1 000 | 仅定位趋势，不得报告偏差数值 |

**两条强制规则**：

- 凡实测 `|bias|/std ≤ 3.92/√J` 的网格点，**只报上界 `δ_min = 1.96·std/√J`，不得报告点估计、不得计算"降偏百分比"**。
- 工作点的选择必须**先做功效核算**（用本表或小规模预扫描），不得先跑完再解释。

> **修订记录**：本表此前使用 `|bias|/std ≈ 0.06`（来自一次小样本、未做显著性判定的观测），
> 据此得出 `J = 5000` 足够。实测重标定后该数字在平衡态下应为 `0.014`，`J` 需求高出一个数量级。
> 结论：**不要用单次小样本的 `|bias|/std` 比值做功效核算**，必须先确认偏差本身已显著。

#### 7.1.4 ★ 通道数 `n` 对所需 `J` 的影响（决定性，ADR-013）

`n` 不是"越大越好"的无害参数——**它直接决定效应量能否被测出**。
实测（复值 `r=2`，SNR=10 dB，`m=200`，`J=1200`，平衡幅度）：

| `n` | DMD `\|bias\|` | `\|b\|/std` | DMD 需 `J` | 偏差显著 | TDMD `\|bias\|` | 降偏比 |
|---|---|---|---|---|---|---|
| **4** | **4.48e-2** | 3.82 | **1** | ✅ | 6.68e-4 | **0.015** |
| **8** | 4.70e-3 | 1.09 | **13** | ✅ | 1.73e-4 | **0.037** |
| 16 | 8.33e-5 | 0.039 | 9 882 | ❌ | 8.77e-6 | 0.105 |
| 32 | 8.49e-5 | 0.063 | 3 826 | ✅ | 3.13e-5 | 0.369 |
| 64 | 6.61e-7 | 0.0008 | **2.4e7** | ❌ | 1.36e-5 | 20.6（反向，无意义） |

**`n` 由 64 降到 4，DMD 偏差放大 6.8 万倍，所需 `J` 由 `2.4e7` 降到 1。**

频率间隔同样显著（`n=8`，其余同）：

| `f_2/f_1` | DMD `\|b\|/std` | DMD 需 `J` |
|---|---|---|
| 1.12 | 4.34 | **1** |
| 1.25 | 1.84 | 5 |
| 1.46 | 1.09 | 13 |
| 1.83 | 0.56 | 49 |

**机制**：`n = 64` 对秩 `r = 2` 的信号是极度冗余的观测，噪声在空间方向被平均掉约
`√64 = 8` 倍，把待测效应完全抹平。**这不是 TDMD 效应弱，而是测试床选错。**

**两条由此确立的规则**：

1. `n` 是**实验轴**（`{4, 8, 16, 32, 64}`），主工作点取 `n ∈ {4, 8}`。
2. **选定任何参数集后，必须先做一次"效应量可分辨性"预扫描**（本表式样，`J` 取 1e3 量级即可），
   再投入实现。否则可能跑到项目末期才发现效应测不出来。

> ⚠️ 上表 `n = 64` 行的"降偏比 20.6（反向）"是**无意义数字**——该工作点下 DMD 偏差本身
> 需 `J = 2.4e7` 才可分辨，比值是两个不可测噪声之比。这正是 §6 规则要防范的误读。
> `n = 4/8` 行两法偏差均远超检测下限，结论可信。

### 7.2 公共随机数（方差消减）

同一 `(SNR, m)` 单元内的 DMD 与 TDMD 估计**必须使用同一条噪声轨迹**。这样两法之差 `Δ^{(j)}` 的方差显著小于各自独立时，`Var(Δ) = Var(a) + Var(b) - 2Cov(a,b)`，其中协方差项在公共噪声下为大正数。

配对比较同时消除了"实现运气"的共同成分，是 `J` 受限时提高统计功效的最有效手段。

### 7.3 样本量扫描的嵌套设计

实验二固定 SNR，扫描 `m ∈ {50, 75, 100, 150, 200, 300, 400, 500}`。为避免为每个 `m` 独立生成数据导致趋势被实现间方差污染，采用**嵌套前缀设计**：

1. 每次实现 `j` 生成一条长序列（`m_max + 1` 个快照）及其噪声；
2. 对 `m_max` 下的每个 `m`，取该序列的**前 `m` 列**作为 `X, Y`，分别运行 DMD 与 TDMD；
3. 得到同一实现下的一族 `{f̂(m)}_{m}`。

**这引入跨 `m` 的相关性，不可直接对合并数据做 OLS。**

正确做法：**逐实现拟合斜率，再对斜率做跨实现统计**

```
对每个实现 j:
    在 log-log 坐标下对 (log m, log RMSE_j(m)) 做 OLS → 斜率 ŝ_j
统计量:  ŝ = mean_j(ŝ_j)
置信区间: ŝ ± t_{0.975, J-1} · std_j(ŝ_j) / √J
```

同理拟合 `log|bias|` 对 `log m` 的斜率。这样报告的是"典型实现的衰减速率"，回避了嵌套相关性问题。

### 7.4 随机种子管理

- 使用 `numpy.random.SeedSequence`，由配置的 `(snr, m, j, purpose)` 通过 `spawn_key` 派生**每一处独立随机源**（相位、噪声、模态增益）。
- 禁止使用全局 `np.random.seed`。
- 每个结果文件必须写入**配置指纹**（配置字典的规范 JSON 的 SHA-256 前 16 位），保证结果可追溯到配置。

> 在原文中**从未出现**，是凭空构造的。

> | `dX` 与 `dY` 的**相关性**（原文只写 `(dX,dY) ~ CN(0,0.05)`） | 决定 TDMD 是否有偏：`trajectory`（X/Y 重叠）下降偏比 →{r_prim:.3f}、`independent` 下 →{r_alt:.3f}，**相差 {r_alt / r_prim:.1f} 倍**；只有前者与原文"TDMD 基本无偏"一致 |

**先前"两套测试台结论矛盾"的解释**：两套测试台的**结论都正确，但各自测的是不同变体**——

**规格层面的教训（已写入实现约定）**：

> **自造的"错误变体"不能直接充当反例。** 必须先用独立证据确认它确实**不等价于**正确实现，

> 正确的做法是：用**原文自身的算例**作为基准（如上表 #3/#4），先确认正确实现能复现原文结论，
> 再确认候选反例在该算例上失败。

## 9. 数值实现注意事项

1. **SVD 精度**：`Z` 的条件数在低 SNR、大 `m` 时会显著增大。使用 `numpy.linalg.svd(..., full_matrices=False)`；若出现 `Σ̄` 最小奇异值相对 `< 1e-12`，改用 `scipy.linalg.svd` 并记录条件数。
2. **`Σ̄^{-1}` 的稳定性**：不得对零奇异值做直接求逆；对 `Σ̄_ii / Σ̄_11 < 1e-12` 的位置置零（记录置零计数）。
3. **数据类型**：实值通道全程用 `float64`；复值通道用 `complex128`。禁止 `float32`。
4. **频率精度**：以 `f_i^true`（Hz）为基准的相对误差可到 `1e-9` 量级，`float64` 足够；但 `bias` 的估计需要 `J` 次平均，注意累加时使用 `math.fsum` 或 `np.longdouble` 累加器以减少舍入。
5. **特征值排序**：`np.linalg.eig` 返回顺序不确定，必须显式按 `arg(λ)` 排序后再配对。

## 10. 秩估计器规格（实验三）

实验三需要 `r̂ = R(σ̂, Z)`。以下是四个候选判据的**精确规格**，实现时不得自行变体。

记 `s_1 ≥ s_2 ≥ …` 为增广矩阵 `Z` 的奇异值序列，`σ̂` 为噪声水平估计。

### 10.1 能量阈值法 `energy`

```
r̂ = min { k :  Σ_{i≤k} s_i²  ≥  (1 - c · (σ̂ / s_1)² ) · Σ_i s_i² }
```

`c` 为可调裕度因子，默认 `c = 1.0`。**局限**：`c` 是自由参数，需额外标定，本身即引入不确定性。

### 10.2 Marchenko–Pastur 法 `marchenko_pastur`

对 `M×N` 的噪声矩阵（此处 `M = 2n`，`N = m`），纯噪声奇异值的理论上界为

```
β = N / M           (若 M > N 则取 M/N)
s_edge = σ̂ · √M · ( 1 + √β )
r̂ = #{ i : s_i > s_edge }
```

**局限**：假定噪声为白噪声且 `M, N → ∞`。当前 `2n = 128`、`m ≤ 500`，有限尺寸效应不可忽略，预期在 `m` 小时偏保守。

### 10.3 Gavish–Donoho 最优硬阈值 `gavish_donoho`

```
β  = min(M, N) / max(M, N)
ω(β) = 0.56 β³ - 0.95 β² + 1.82 β + 1.43        # 原文给出的多项式拟合
τ  = σ̂ · ω(β) · median(s)
r̂ = #{ i : s_i > τ }
```

**这是三个判据中最推荐的**：只依赖 `σ̂` 与观测到的中位奇异值，无自由参数，且为已知最优（渐近 minimax）硬阈值。

### 10.4 残差法自举估计 `σ̂`（数据驱动，无需外部输入）

```
σ̂_res = ‖ Z - Ũ_r̂ Σ̃_r̂ Ṽ_r̂* ‖_F / √( (2n) · m )
```

需与上述任一秩判据迭代至收敛（初始 `r̂` 由能量法给出，迭代上限 10 次）。

**该方案对应"噪声估计完全未知"的场景**，是实验三最贴近实际应用的配置。其自举得到的 `σ̂` 与真值的比值定义了等效的失配倍数 `k_eff = σ̂_res / σ_true`，须一并报告。

### 10.5 失效判据

若 `σ̂` 的失配导致 `r̂ ≠ r_true`，则记录 `rank_mismatch = True`。须知：**`r̂ > r_true` 与 `r̂ < r_true` 的后果不对称**——前者引入噪声子空间、使偏差回升；后者截掉真实模态、产生极大误差。报告须分列两种误判的占比，不得只报总误判率。

1. **`std` 比稳定落在 0.99–1.01**，即**未观察到 TDMD 的方差代价**。这与假设 H3 相悖——若正式实验确认，则 H3 应判定为**不成立**，而这本身是一条有价值的结论（TLS 在此设定下并非以方差换偏差）。
2. **SNR 越低、降偏效果越强**（20 dB 时仅 11–20%，5 dB 时达 78–92%）。这与"高 SNR 时 DMD 够用"的预期一致。

实值 `r=4` 通道（`J = 1500`，含显著性标注）：

| SNR | 模态 | `\|bias\|`/`std` DMD | `\|bias\|`/`std` TDMD | 显著性 | 降偏 |
|---|---|---|---|---|---|
| 10 dB | 1 | 0.037 | 0.035 | 两者均**不显著** | 无意义 |
| 10 dB | 2 | 0.199 | 0.142 | 两者均显著 | 29% |
| 5 dB | 1 | 0.003 | 0.065 | DMD 不显著 | 无意义 |
| 5 dB | 2 | 0.202 | 0.184 | 两者均显著 | 10% |

**关键差异**：实值通道的降偏收益（10–29%）**显著弱于**复值通道（48–92%），且模态 1 的偏差长期处于检测下限之下。这是规格 §6 与 §7.1 中"只报上界"规则的具体触发场景，也是 M4 验收门必须解释的现象（见 `implementation-plan.md` 风险 R11）。

## 12. 实测性能与工时预算

### 12.1 ★ 关键工程配置：锁定 BLAS 单线程

测量环境：Python 3.12.10，numpy 2.5.3（scipy-openblas 0.3.34，`MAX_THREADS=24`），`n = 64`。

本项目矩阵规模很小（`2n × m ≤ 128 × 500`），**OpenBLAS 的多线程调度开销远大于计算本身**。
对 128×200 复数矩阵做一次 SVD 的实测耗时：

| `OPENBLAS_NUM_THREADS` | 单次 SVD |
|---|---|
| **1** | **5.27 ms** |
| 2 | 11.14 ms |
| 4 | 14.79 ms |
| 8 | 28.06 ms |
| 默认（未设置） | 70.50 ms |

**单线程比默认快约 13 倍。** OpenBLAS 在库加载时读取该环境变量，因此必须在 `import numpy`
之前设置。工程落点：仓库根 `conftest.py` 与 `tests/conftest.py` 在所有 numpy 导入前
设置 `OPENBLAS_NUM_THREADS=1`（及 `OMP_NUM_THREADS` / `MKL_NUM_THREADS`）。

> **教训**：本次校验最初测得"单次实现 191 ms"，据此推断若干个实验需要数小时至数十小时，
> 一度误判项目不可行。真实瓶颈是线程超额订阅而非算法或矩阵规模。**性能异常时应先查
> BLAS 线程配置，再考虑改算法或加算力**——尤其当矩阵规模远小于线程数时。

### 12.2 单次运算耗时（单线程）

DMD + TDMD 两法合计，单核，单线程 BLAS：

| 通道 | 单法 | 两法合计 | 含数据生成的一次完整实现 |
|---|---|---|---|
| 复值 `r=2` | DMD 3.89 ms / TDMD 9.45 ms | 13.34 ms | **16.78 ms** |
| 实值 `r=4` | DMD 1.81 ms / TDMD 4.18 ms | 5.99 ms | **7.77 ms** |

### 12.3 全部实验的推算工时

按 §7.1 修订后的取值（`J = 5000`，关键点 `J = 20000`）：

| 实验 | 配置 | 推算耗时 |
|---|---|---|
| 实验一（偏差可分辨组） | 2 通道 × 3 SNR × `J=5000` | ≈ 5 min |
| 实验一（高 SNR 组，只报上界） | 2 通道 × 3 SNR × `J=5000` | ≈ 5 min |
| 实验一（扩展网格） | 2 通道 × 8 SNR × `J=1000` | ≈ 2 min |
| 实验二（`m` 序列） | 2 通道 × `J=20000` × 8 个 `m`（嵌套） | ≈ 25 min |
| 实验三（7 个 `k` × 3 判据） | 2 通道 × 7 × 3 × `J=5000` | ≈ 30 min |
| **合计** | | **≈ 1.2 小时（单核）** |

**结论**：**单机单核串行即可承受，不需要并行框架。** 多进程会显著增加种子管理与结果
归并的复杂度，收益不成比例——尤其在单线程已比默认快 13 倍的前提下，
"再多开进程"通常只会重新引入线程/进程超额订阅问题。

若确需加速，优先级依次为：
1. 确认 BLAS 单线程已生效（收益最大、成本最低）；
2. 实验二的嵌套循环内复用 `Ṽ_r` 的增量 SVD；
3. 最后才考虑多进程。
